Anatomy 4 Bagian Widget

Spesifikasi
1 Tombol Mengambang Launcher

Terletak di pojok kanan bawah. Memiliki indikator jumlah pesan (*unread badge*), efek animasi *float*, serta *tooltip* pemicu.

2 Header Judul Header Bar

Menampilkan identitas **SMA Muhammadiyah 1**, avatar CS Humas, status keaktifan *Online*, tombol bersihkan percakapan, dan tombol tutup.

3 Area Percakapan Chat Body

Wadah *bubble chat* biru/putih, timestamp, indikator mengetik (*bouncing dots*), serta *Quick Reply Chips* (PPDB, SPP, Tahfidz, Lokasi TU).

4 Kolom Input Pesan Input Footer

Form masukan teks, tombol unggah lampiran berkas pendaftaran, emoji shortcut, dan tombol kirim dengan aksen warna utama hijau sekolah.
